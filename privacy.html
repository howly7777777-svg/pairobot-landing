Privacy Policy Meeting AI

Last Updated: May 2026

PaiRobot is built for high-trust workflows. This policy describes what data may be processed, where data can be retained, and how users control retention and export.

1. Privacy-First Product Defaults

  • Default retention mode is No Retention.
  • Meeting results are not auto-saved to vendor-side database by default.
  • Users can explicitly choose local save or customer-managed export.

2. What Data May Be Processed

  • Meeting audio files uploaded by user action.
  • Generated transcript, summary, decisions, action items, and email drafts.
  • Technical diagnostics for reliability (request status, timestamp, error code).
  • Purchase entitlement metadata for in-app subscription/one-time unlocks.

3. Retention Modes Users Can Choose

  • Mode A - No Retention (default): Session-only output, no automatic persistence to vendor database.
  • Mode B - Local Device Storage: Export JSON to local app storage on user device.
  • Mode C - Customer-Managed Export: User selects destination path/storage controlled by customer.

4. BYOK and Credentials

PaiRobot uses BYOK architecture. API keys entered by users are encrypted and stored locally on their device. PaiRobot does not upload API keys to a vendor key vault.

5. Third-Party Processors

  • Google Gemini API (generation/summarization/transcription features, depending on enabled flow).
  • Communication providers configured by users for user-triggered workflows (LINE/Telegram/WeCom).

PaiRobot does not sell personal data.

6. User Consent and Control

  • Users can choose retention mode in-app before export.
  • Users can copy, export, or delete local export records and files.
  • Users can revoke AI usage in settings where applicable.
